# Privacy Policy

**Effective Date:** 2026-01-08

## Data Collection & Storage
We value your privacy. This extension ("Workday: Better Autofill") is designed to operate entirely locally on your device.

1. **Local Storage**: All personal information (names, addresses, work history, resume files) entered into this extension is stored locally within your browser using the Chrome Storage API (`chrome.storage.local`).
2. **No Remote Servers**: We do not operate any backend servers. Your data is **never** transmitted to us or any third parties. It never leaves your browser environment, except when you explicitly use the autofill feature to populate a form on a third-party website (e.g., Workday).

## Permissions
- **Storage**: Required to save your profile data so you don't have to re-type it.
- **ActiveTab / Scripting**: Required to interact with the Workday job application page to autofill your information.
- **Host Permissions**: Limited to `*://*.myworkdayjobs.com/*` to ensure the extension only runs on relevant job sites.

## Data Deletion
You can delete all stored data at any time by clicking the "Delete All Data" button in the extension popup. This action immediately clears the local storage associated with the extension.

## Contact
If you have any questions, you can check the source code or contact the developer via the distribution platform.
